# Original prompts

The five briefs this folder was built from, kept word for word so any document can be regenerated or challenged later.

## 1. Website audit

Output: [01-website-audit.md](01-website-audit.md)

```text
Act as a senior web designer specializing in local service businesses.

Analyze this website:
https://www.mjg-cleaning-services.com/

Your task:

1. Identify weaknesses that reduce lead generation.
2. Identify trust issues.
3. Identify missing SEO opportunities.
4. Suggest improvements that would increase quote requests.
5. Compare the website against top-performing cleaning company websites.
6. Create a list of recommended pages and sections.

Output a professional website audit.
```
